# 2026-08-29 H100 real smoke

Status: valid protocol smoke; not performance evidence  
Evidence confidence: `ARTIFACT_BACKED`

## Question and hypothesis

Could the A/B/C harness, authentication, health checks, Prometheus accounting, GPU sampling,
result validation, and real multi-request gateway aggregation operate end to end on an H100? The
hypothesis was that all arms would complete without failures and C=8 would form batches larger than
one. This experiment did not test repeatability or production performance.

## Environment and workload

One NVIDIA H100 80GB HBM3, driver 610.57.04, CUDA toolkit 13.0; Python 3.12.13; Go 1.27.0; vLLM
0.26.0; Transformers 5.14.1. Model `Qwen/Qwen3.8-27B` (revision not recorded), BF16/FP8 KV, TP=1,
32768 context, 16 sequences, 8192 batched tokens, prefix caching off. Gateway/repo SHA
`c62661e67c94052f8b1269b73852424bec31be61`.

Non-streaming A/B/C ran at concurrency 1 and 8, once each, with 10 warmups and 40 measured requests,
`n=1`, temperature 0, top_p 1, max_tokens 128, seed 1. All 240 measured requests succeeded; all six
files validated. C=8 formed mean batch size 5 and p95 size 8; C=1 batches stayed size one.

## Interpretation and decision

The run proves protocol viability, metric/counter collection, and actual gateway batch formation.
Its one repetition, fixed arm order, single host/model, and small request count prohibit improvement,
speedup, or production claims. Proceeded to a rotated three-repetition full sweep. Archive SHA-256:
`e0cab63930f658e0392f5f04e03a0ec6e8a38af403dd33c1206914b41523fa82`.
